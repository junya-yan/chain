# キャラクター画像の入れ方

このフォルダに画像と `manifest.json` を置くと、コードを触らずにキャラクターが
差し替わる。置かなければ手続き的描画のまま動くので、描けたものから 1 体ずつ
入れていける。

## 形式

**PNG（32bit RGBA）のスプライトシートを推奨。GIF は避けたい。**

理由がこのゲーム特有にある。

- 歩きのコマは**実際の移動距離**に同期している（止まれば脚も止まる）。さらに
  2x/4x の早送りと一時停止がある。GIF は自前の時計でアニメするので、
  早送りでも一時停止でも勝手に動き続け、絵と物理がずれる。
- GIF の透過は 1bit。暗いジャングル背景に置くと輪郭がギザギザに出る。
  PNG のアルファなら滑らかに抜ける。
- GIF は 256 色。原作のような塗りには足りないことがある。

WebP でも同じことができる（ファイルは小さくなる）。連番 PNG より 1 枚の
シートのほうが読み込みが速い。

## シートの作り

1 枚の PNG に、コマを**横に並べ、状態ごとに行を変える**。

```
     コマ0  コマ1  コマ2  コマ3  コマ4  コマ5
行0  [歩き][歩き][歩き][歩き][歩き][歩き]
行1  [登り][登り][登り][登り]
行2  [落下]
行3  [待機][待機]
```

- 全コマ同じサイズ（例 64x64）。余白も含めて揃える。
- 背景は完全透過。
- **基準点を揃える**こと。動物は「足元の中心」を基準にすると地面にきれいに立つ。

## manifest.json

```json
{
  "lion": {
    "src": "lion.png",
    "frameW": 64,
    "frameH": 64,
    "anchorX": 32,
    "anchorY": 58,
    "scale": 0.55,
    "clips": {
      "walk":  { "row": 0, "frames": 6, "perPixels": 9 },
      "climb": { "row": 1, "frames": 4, "perPixels": 11 },
      "fall":  { "row": 2, "frames": 1 },
      "idle":  { "row": 3, "frames": 2, "fps": 3 }
    }
  },
  "bird": {
    "src": "bird.png",
    "frameW": 48,
    "frameH": 48,
    "anchorX": 24,
    "anchorY": 40,
    "scale": 0.5,
    "clips": {
      "perched":  { "row": 0, "frames": 2, "fps": 2 },
      "startled": { "row": 1, "frames": 2, "fps": 12 },
      "flying":   { "row": 2, "frames": 4, "fps": 14 }
    }
  }
}
```

| 項目 | 意味 |
| --- | --- |
| `anchorX` / `anchorY` | コマ内の基準点。動物は足元の中心。省略時はコマ中央下 |
| `scale` | 論理座標へ描くときの倍率。当たり判定は変わらない |
| `perPixels` | 何 px 動くごとに 1 コマ進めるか。**歩き・登りはこちらを使う** |
| `fps` | 秒あたりのコマ数。待機や羽ばたきなど、移動と無関係なものに使う |

`perPixels` を指定したクリップは移動距離で送られるので、早送りでも一時停止でも
絵と物理がずれない。歩きにこれを使うと、速度が変わっても歩幅が破綻しない。

## 大きさの目安

当たり判定はライオン 16x24 論理px で固定（ステージ設計がこの値に依存している）。
画像はこれより一回り大きくてよく、現在の手続き的描画は約 1.35 倍で描いている。
`anchorY` を足元に合わせておけば、`scale` を変えても足の位置はずれない。

論理画面は 800x600。原作の見た目に寄せるなら、ライオンは高さ 40〜55 論理px あたり。
元絵は 2〜4 倍のサイズで描いて `scale` で縮めると輪郭がきれいに出る。

## 使える名前

- `lion` — 歩く動物。クリップ: `walk` / `climb` / `fall` / `idle`
- `bird` — 鳥。クリップ: `perched` / `startled` / `flying`

足りないクリップは自動で他のもので代用する（`climb` が無ければ `walk` を使う）。
まず `walk` の 1 行だけ描いて入れてみるのが早い。
